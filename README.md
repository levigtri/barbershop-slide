# BarberPro: apresentação

Slides da apresentação do projeto BarberPro, uma API de agendamento para barbearia. Feitos com [reveal.js](https://revealjs.com/).

Acesse em: https://levigtri.github.io/barbershop-slide/

## Navegação

- Espaço ou seta para a direita: avança
- Setas para cima e para baixo: sub-slides
- `F`: tela cheia
- `Esc`: visão geral dos slides
